# PulseBI AI Analytical Tool

## Overview

PulseBI AI Analytical Tool is an end-to-end business intelligence and data analytics project built using Google Colab and Python.

The project performs:
- Data Cleaning
- Exploratory Data Analysis
- KPI Analytics
- Correlation Analysis
- Forecasting
- Anomaly Detection
- Customer Segmentation
- AI Insight Generation

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Scikit-learn
- Prophet
- XGBoost
- SHAP

---

## Features

- Dataset Understanding
- Data Cleaning Pipeline
- Interactive Visualizations
- KPI Analytics
- Sales Forecasting
- Correlation Heatmaps
- AI Business Insights
- Anomaly Detection
- Customer Segmentation
- Executive Summary Generation
